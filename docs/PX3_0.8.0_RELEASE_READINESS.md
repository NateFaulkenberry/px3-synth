## Fixed tonight (with tests)

**DSP and modulation**
- DRY LEVEL / DRY PAN and filter KEY ignored modulation; the route showed on the knob and did nothing.
- An envelope modulating oscillator macros made ramped controls (DIGITAL RATE/FOLD and the like) swing every block.
- SMOOTH RND jumped once a cycle; S&H / SMOOTH RND were the same series on all three LFOs.
- Filter key tracking swept every note's onset (2.4 dB off at the attack).
- DIGITAL FOLD transposed the sine instead of folding it. It is now a real sine wavefolder.
- An external MIDI clock in TRANSPORT mode stepped the LFO (it held still on half its blocks).
- Modulated delay WOBBLE / MOD DEPTH and compressor INPUT / OUTPUT / MIX clicked at block boundaries (OUTPUT measured 23.6×).
- Clearing a reverb IR raced the audio thread.
- Shimmer and DRIVE constants depended on the sample rate.
- Host state drifted by ~1e-8 per reload (skewed float ranges). Saving an unedited state now reproduces it exactly.

**UI**
- MENU › Settings did nothing in release builds, and no version was shown anywhere.
- Bypassed ENV cards left MODE / LOOP / SYNC / KEY and the curve editable; bypassed oscillators left SLOP live; bypassed filters left KEY TRK / KEY and the comb knobs live.
- Delay captions could show granular names on a Tape delay.
- A resize could put the keyboard above an open macro depth panel.
- SETTINGS' Analog Engine menu didn't follow automation or preset loads.
- The idle editor redrew three oscillator cards, the AMP ENV card and the wheels 30–60 times a second: **93% → 4% of a core**.
- Synced LFO cards flipped their controls twice a tick.

**Earlier in this session:** the dropdown click race, the M6 matrix colour, a test crash that had hidden the macro depth tests, test runs writing into the user's real preset library and settings, the sub osc colour, the INIT semantics, and all the UI requests.

## Outstanding: for you to decide (not fixed)

1. **Master overshoot at all-max settings (pre-existing, not a regression).** With the Analog Engine on and every source, fader and the master at maximum, dense chords peak at 1.07–1.14 (up to +1.1 dBFS). v0.7.6 measures **identically**. CI never caught it: its regress step pipes through `tee`, which discards the exit code, so it showed green with 8 failures in v0.7.6 too. Options: add a master safety clipper or soft limiter (a sound change); lower the console's output trim; or ship as documented (this is in the release notes). Also decide whether CI should gate regress (`set -o pipefail`). That would turn CI red until (1) is resolved.
2. **Envelope → in-voice destinations run at host-block rate.** The first block of a note gets envelope 0, and pluck timing depends on the host buffer size (pinned by the matrix test at ≤ 1 block). This is how v0.7.6 behaved too. A per-sample or sub-block evaluation is the fix if fast filter plucks matter for 0.8.
3. **DRIVE has no oversampling.** It stays below −59 dB aliasing up to 3 kHz fundamentals, but reaches −24 dB at 5 kHz with full HARD drive. Documented as a known limit.
4. **LFO 1 display flicker while playing.** Not reproduced offscreen. Suspected interaction with the spark overlay above the wheels and low keys. Needs your answers: any key or only low ones? Wheels untouched?
5. **CLOUD reverb +1.7 dB at 96 kHz vs 48 kHz** (the network itself, not shimmer).
6. **Smaller UI leftovers:**
   - invisible duplicate controls still bound to vibe / env / amp parameters;
   - 24 additive `harmonics.1-8` parameters have no on-screen control;
   - AMP ENV's enable is forced on every tick, which fights host automation of it;
   - the designer exposes `binding` / `label` fields that do nothing.
7. **Sub osc waveform levels are not matched** (saw ≈ −1.8 dB vs sine).
