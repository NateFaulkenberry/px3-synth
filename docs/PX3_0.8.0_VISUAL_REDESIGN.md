# PX3 0.8.0 visual redesign, single-panel navigation and FX UI

The owner's direction: a modern, VCV Rack-inspired single-window instrument
(not a clone and no VCV artwork). It should be cohesive, tactile, dense but
legible, and dark. It must read as a synthesizer, not a web dashboard. This
phase builds on the layout engine (`PX3_0.8.0_UI_FOUNDATION.md`) and the
in-window modulation work (`PX3_0.8.0_MODULATION_UI.md`).

## Design decisions

1. **The modules are the structure.** Each card is a module faceplate. It has a
   quiet vertical gradient, a dark outer edge, a one-pixel lit top bevel and a
   title band. Across the top runs a 2 px stripe in the module's identity
   colour. The old per-card translucent tints, two-tone gloss, drop shadows and
   full-bleed artwork pictures are gone. They were the main reason every card
   looked like it came from a different style, and the drop shadows were also
   blurred on every paint. The window behind the modules is a flat dark
   chassis, and the header is a rail. There are no screws and no window
   outline.
2. **Colour means identity or state.** Only these things carry colour:
   - each module's stripe and its knob value arcs (OSC blue, FILTER red,
     AMP green, LFO/ENV purple, one hue per FX)
   - the selected tab's underline
   - a lit switch's stripe
   - modulation rings in their source colour

   Bypass greys the stripe and dims the title, the same way everywhere.
   Surfaces and text are neutral.
3. **One knob family.** Every knob has a recessed track ring carrying the value
   arc. The cap is turned: gradient, edge and lit upper rim, with a pointer
   line. Size follows importance:
   - feature knobs (AMOUNT/MIX/INTENSITY) are large
   - main controls are medium
   - tuning and secondary controls are small

   Bipolar ranges fill from their centre, so a detune at 0 shows nothing lit.
   Hover lifts the rim and adds a faint accent halo. Disabled or bypassed
   knobs are greyscale. The mod rings and live-value arc from the modulation
   UI are kept. The 48-dot "grain" and the per-knob drop shadow are gone, so
   a knob is cheaper to paint.
4. **Gestures** (`ParameterKnob.h::applyKnobGestures`, applied wherever a knob
   is bound):
   - drag (vertical or horizontal)
   - **Cmd- or Alt-drag for fine adjustment**: relative, about a fifth of the
     rate. Shift is left alone because Shift-click is MIDI learn.
   - **double-click resets to the parameter default**, except on macro knobs,
     where double-click is macro assignment
   - FX cards also swap a knob's caption for its value while it is hovered or
     dragged. Elsewhere a readout already sits under the knob.
5. **Printed legends, not chips.** `ChipLabel` now draws as a printed caption on
   the faceplate, with no pill. A row of filled pills was most of what made
   the old panels read as a web form. Switches (`ToggleChipButton`) are
   recessed keys: an inset well, and when on, a stripe and caption in the
   card's colour. Dropdowns are inset wells with a thin chevron.
6. **Navigation: VOICE / MOD / FX / MIX + settings gear.**
   - VOICE is the synthesis strip: SUB + OSC 1-3, FILTER 1-2 with routing, and
     AMP, side by side at every supported size. The AMP and FLT tabs are gone.
     Their section indices still exist, and selecting them shows VOICE, so
     presets, tests and host state that stored them keep working.
   - MOD keeps the LFO/ENV cards with the routing panel beside them.
   - FX is a rack: the send chain in signal order, five modules across at
     the default size (fewer when narrow), rows sharing the page height so
     all nine modules are on screen without scrolling at 1518x918.
   - MIX is unchanged in structure.
   - Patch bar, macro strip and keyboard are shared by every page.

   This follows the pattern Vital and Pigments use, where the synthesis core
   is one page and modulation and effects are their own pages. The planned
   alternative, Serum-style tabs with a fixed synthesis strip, would have
   needed the oscillator cards to fit in about 350 px of height, which made
   them unreadable.

   There are no floating windows. The only file chooser is the IR loader's
   system dialog.
7. **Sizes.**
   - Default 1518x918 (unchanged).
   - Minimum **1100x700** (was 980x600). This is the smallest size where
     the VOICE strip keeps every knob readable and no caption clips. The test
     checks it.
   - Maximum 2400x1400.
   - Below the size where FX modules fit, the rack drops columns
     (`fx.grid.minCardWidth` 262) and scrolls vertically
     (`fx.grid.minRowHeight` 330). The MOD cards scroll beside the routing
     panel, as before.
   - Oscillator tuning knobs sit in a 2x2 grid (`osc.N.row.tuning`, grid
     layout in the scene), so they keep their size when the card narrows. They
     used to wrap into one column and collapse to 0 px.
   - Everything stays scene/flex-driven and editable in the designer.

### Typography

One typeface (the platform UI sans; menlo for numeric displays) at fixed roles:

| Role | Size | Weight | Tracking | Used for |
|---|---|---|---|---|
| heading | 11.5 | bold | 0.10 | module titles |
| tab | 11 | bold | 0.08 | VOICE / MOD / FX / MIX |
| label | 10 | bold | 0.06 | knob/dropdown captions, switch text |
| secondary | 9 | plain | 0.06 | sub-section headings (ANALOG DRIFT), hints |
| value | 10.5 | plain | 0 | readouts (12.0 kHz, 250 ms) |
| display | 9.5 | mono | 0 | numbers inside displays |
| control | 11 | plain | 0 | text in dropdowns and buttons |
| menu | 13 | plain | 0 | popup menus |

`InstrumentLookAndFeel` is set on the editor, so every child without its own
look inherits it: labels, dropdowns, menus, buttons, tooltips, scrollbars and
slider bubbles. `KnobLookAndFeel` and the filter and LFO combo looks derive from
it. A `ChipLabel` picks the value role when its text has digits or lowercase,
and the label role otherwise. There are still about 150 literal `FontOptions`
sizes across the panels. The look-and-feel maps the common ones onto the roles
(`getLabelFont`), but not every literal has been rewritten (see remaining
issues).

## FX UI

| Card | Change |
|---|---|
| **DRIVE** (new, stage 8) | CLIP (SOFT/HARD/ASYM), DRIVE, TIGHT, TONE, LEVEL, MIX, with power. Strip node "DRIVE", colour `cards.drive` (#E0603A) |
| **VIBE** / **ANALOG** | Two cards since the VIBE/ANALOG split. VIBE: MODE, STEREO, SPEED, LEVEL, INTENSITY (`fx.vibe.*`). ANALOG: STYLE and AMOUNT (`fx.analog.*`), ahead of the chain. VibeComponent was removed |
| **DELAY** | Third row by algorithm: TAPE → QUALITY, WOBBLE, SLIP; MODULATED → MOD DEPTH; other algorithms fold the row away. Same in the standalone PX3 Delay (parity test) |
| **REVERB** | DEPTH/RATE → MOD DEPTH/MOD RATE; PRE → PRE-DELAY; new SHIMMER (CLOUD); AMOUNT → MIX. In IR mode a footer shows the IR name, LOAD IR... (async FileChooser, wav/aif/aiff/flac; errors show the processor's reason in place of the name) and CLEAR (`ReverbIrStrip.h`, card footer API) |
| **CHORUS** | SPREAD → PHASE, CHARACTER → VINTAGE, MIX → DRY/WET, AMOUNT → INTENSITY |
| **DOOM** | ALT → SHIFT. TIME/MODIFY → WET TIME / WET CHAR; LENGTH/MODIFY → LOOP LEN / LOOP CHAR. Alternates: CROSS → INTERFERE, EQ → TILT, FADE → DECAY, BLEND → DRY LOOP, GLUE → **DRIVE**, BALANCE → LOOP/WET. SPREAD → WIDTH. Tooltips name the per-mode meaning |
| **LUCY** | ALT → SHIFT, V-PRE/V-POST → VERB FIRST / VERB LAST, SLOPE → FILTER SLOPE, WEIGHT → PROTECT, FILTER → BAND, THRESHOLD → LIMIT, DECAY → VERB SIZE, SPREAD → WIDTH, GLOBAL → AMOUNT, FREEZER → FROZEN MIX |
| **MOOD** | WET TIME / WET MOD / LOOP MOD follow the mode: REVERB DECAY/SMEAR, DELAY TIME/REPEATS, SLIP LAG/PITCH; ENV SENS, TAPE SPEED, STRETCH WALK, with matching tooltips |
| **SPREAD** | Out of the reorderable strip and shown after the chain (it runs on the master bus). The basic view is WIDTH, LOW MONO, MIX and AMOUNT. **ADVANCED** unfolds MODE, DECORR, CENTER, SIDE TONE, LOW WIDTH, HIGH WIDTH and HIGH XO. Reordering the strip re-appends Spread, so the processor still gets a full permutation |
| every card | One-line description as the card and power tooltip; every control has a behaviour tooltip |

The Chorus, Reverb, Spread, Drive and Vibe rows are declared once in
`shared/UI/Fx/FxCardDeclarations.h` and shared with the standalone products, as
the Doom and Lucy layouts already were. Parameter IDs are unchanged. The Synth
attaches the new cards by parameter ID (`attachCardControls`).

Also added on request during the phase: a **SYNC** switch under LOOP on each ENV
card (`mod.envN.sync`).

## Performance

`PX3Bench ui`, offscreen paint, 1518x918, release:

Two interleaved runs of each binary under the same load:

| | before (main UI) | after |
|---|---|---|
| full editor repaint (mean) | 3.16 / 3.17 ms | 3.01 / 2.96 ms |
| timer + idle animation repaint (median) | 6.23 / 6.17 ms | 5.98 / 5.99 ms |
| timer + live note + automation (median) | 6.82 / 6.76 ms | 6.47 / 6.45 ms |

Paint got cheaper: knobs no longer draw 48 noise dots and a drop shadow, cards
no longer blur a DropShadow or scale artwork, and labels are plain text. The
redesign added about 20 parameter knobs (Drive, Vibe, Delay extras, SHIMMER,
SYNC). That first made the 30 Hz tick about 1 ms slower, because
`refreshMidiMappingUI` looks up every knob's parameter by name. The tick now
skips the two expensive refreshes (live modulated position and route rings)
for knobs on hidden pages. They catch up on the first tick after the page
opens. MIDI, macro and Select Mode state stay current everywhere.

The before numbers were measured with another worktree's build of the same UI
code (main plus DSP-only changes), because the session's first build dir
belonged to another agent.

## Tests

New suite `PX3Tests visual` (`tests/Tests/TestsVisualRedesign.cpp`, 15
checks). It passes with and without the shipped UIConfig. It checks that:
- every visible knob on VOICE/MOD/FX/MIX is bound to a real parameter and is
  what a click at its centre hits (141 knobs)
- the minimum size is 1100x700, and no caption, readout or switch text needs
  more than its width at the 72% fit floor on any page (139 captions measured)
- VOICE shows OSC, FILTER and AMP together at the minimum
- the tabs are VOICE/MOD/FX/MIX
- the FX cards expose all 13 new parameters
- the Drive card is present
- Spread is out of the strip but still on the page, and folds its advanced
  controls
- Delay's extra row follows the algorithm
- the IR loader shows only in IR mode
- the stale labels are gone
- the ENV SYNC switch writes `mod.envN.sync`

Updated, intentional:
- `EditorPaint_SecondarySectionsShowTheirOwnPanels`: AMP and FLT now show the
  VOICE strip
- `FxChain_ShippingConfigDefinesTheStripAndGrid`: 5 columns
- `BusInsert_TranslucentSheetShowsTheDimmedBackdrop`: the threshold is now
  0.10. The darker chassis made the sheet's own face a larger part of the
  reading. This is a looser check, so a sharper one is listed below.

Full suite (release, PX3_UI_DESIGNER=OFF, build outside the repo, plugin copy off): see the progress log for the final count.

## Remaining issues

- About 150 literal font sizes remain in panel code (MOD cards, mixer, settings,
  preset browser). They fall through `InstrumentLookAndFeel::getLabelFont` to
  the scale where they are plain labels, but text a component paints itself
  still uses its own size.
- The macro strip still uses the pale macro knob look. It is deliberately a
  different control, and a test pins its CC overlay against a pale substrate.
  Its "Depth" buttons are the old style.
- The MOD page's ENV cards are taller than the page at 918 px and scroll (as
  before). The routing panel's patch view is mostly empty with no routes.
- Mood and Delay are still hand-laid components (shared with the standalones),
  so their insides do not follow the FxCard row system. Mood's combos are tight
  at five columns.
- The filter and AMP card insides are still hand-laid (see UI foundation doc),
  so their spacing is tuned through UIConfig rows rather than scene nodes.
- The bus-insert backdrop test needs a sharper measure under the new chassis.
- The standalone was not launched interactively (no GUI session). The new
  gestures (Cmd/Alt fine drag, double-click reset), hover value captions and
  the IR file dialog are untested by hand.
