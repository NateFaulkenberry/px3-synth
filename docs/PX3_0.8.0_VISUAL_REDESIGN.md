# PX3 0.8.0 visual redesign, single-panel navigation and FX UI

Phase brief: modern, VCV Rack-inspired single-window instrument (not a clone),
one token/type system, one knob family, FX cards that explain themselves, the
new DSP parameters surfaced. See the progress section at the end.
