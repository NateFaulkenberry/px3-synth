**Status:** the features are implemented and covered by automated tests (1,703

## 1. Architecture

**UI layout.** One data-driven flex/grid engine (`UILayout.*`) supports
direction, wrap, x/y gaps, padding, margin, align/justify, px / % / auto
sizing, grow/shrink, min/max, order, absolute children and grid tracks. The
scene document `InstrumentScene.json` (schema v2, strictly validated) holds
about 180 nodes with stable IDs. Components register by ID (`SceneBinding`)
and get their bounds from the solver. Layout is resolved only when the size or
the document changes. The shipped layout is compiled in, and user layouts are
saved separately from presets, so layout never touches sound.

**Designer.** It is compiled only with `PX3_UI_DESIGNER`, and release builds
contain 0 designer symbols. An overlay on the live editor provides:
- hover highlight; click selects the deepest object; Alt/Cmd-click or Esc
  selects the parent
- drag and 8 handles that edit the real layout properties; the frame is always
  drawn from the resolved rect
- a contextual inspector (dev window), snap, undo/redo with coalesced drags,
  lock, visibility, reorder
- save, load, and reset to default

**Single window.** Navigation is VOICE (OSC, FILTER and AMP together) / MOD /
FX / MIX / settings. No instrument feature opens a window; the ROUTES window
is deleted. Window size: minimum 1100×700, default 1518×918, maximum
2400×1400.

**Modulation.** The typed graph (global LFO/macro routes) is unchanged. ENV
routes into voice-local destinations are now evaluated **per voice**
(`VoiceModulation.h`, shared route arithmetic). The UI provides:
- source sockets (patch strip, card corners, MOD patch view)
- drag onto any destination knob to create a route
- coloured rings on routed knobs
- a route list with depth, polarity, curve and delete

## 4. Performance (DSP, matched builds vs 0.7.6 `24986e4`)

**Setup.** Both builds are RelWithDebInfo / Ninja with the same JUCE 8.0.4
source and the same machine (M2 Max), measured with `PX3Bench` at
48 kHz / 512. Runs were interleaved and gated on load < 4. Raw output is in
`/tmp/px3-gate-bench*`.

**Finding and fix.** Two clean interleaved pairs showed every
filter-using scenario 15–24% slower in 0.8. Bisecting with matched builds
pinned it to the new-filter-models commit: three mode tests sat ahead of the
biquad in the per-sample path. After `b25d394` (biquads first, models out of
line), "16 voices + filters" measures **1,645 µs, against 1,670 µs for
0.7.6** (it was 1,886 µs).

**After the fix.** A fresh full-table pair agrees to within ±2% for every row
measured on a quiet machine:
- SINE −0.5%, SUPERSAW −0.5%, PX3 −0.5%
- WAVETABLE 1–64 voices −0.8 to +1.8%
- all bus-insert rows −1 to −2%
- rapid triggering and voice stealing −1 to −2%
- 32–48 voices with everything on −0.4 to +2.6%

0.8 also had **fewer** deadline misses than 0.7.6 in that run (for example,
64 voices + both buses: 145 for 0.7.6, 0 for 0.8). The first third of that
0.8 run (idle through "16 voices + mixer automation") ran while machine load
jumped to about 12, a concurrent build. Those rows read +10–16% with
inflated p99 and are **not valid**. In the earlier clean pairs the same rows
were +0–5% (idle +5%, 1 voice +4%, 16 typical +1%). That is a small fixed
per-block overhead from 0.8's added control-rate work.

**Not yet measured:**
- the full rate/block matrix
- a final quiet full-table repeat after all fixes
- native UI CPU vs 0.7.6

**Offscreen UI paint is faster than 0.7.6:** full repaint 2.96–3.01 ms
against 14.6 ms for 0.7.6, and timer + live note 6.45 ms against 15.6 ms (see
`PX3_0.8.0_VISUAL_REDESIGN.md`).

**Memory:** processor +5% per instance; editor about 5× smaller (see the
release-gates doc).

## 5. Known issues (honest)

- Never driven with a real mouse: route dragging, designer handles, the IR file
  dialog and tab-hover switching are tested only with simulated events.
- Visual polish:
  - Mood's MIX knob renders very small.
  - Lucy and Doom cards are cramped.
  - The macro strip keeps old white knobs and "Depth" buttons.
  - The MOD page ENV cards scroll at the default size.
  - About 150 literal font sizes remain in self-painting panels.
- Some panel interiors (filter, AMP envelope, Mood, Delay) are still laid out
  in code tuned through UIConfig, not scene nodes. They are not yet editable
  in the designer.
- Depth is edited from the route list only, not by dragging the ring.
  Polarity/curve are editable only for drag-made routes.
- Supersaw: ~4.5 dB quieter at full DETUNE in the synth (by design, see above).
- IR mode is briefly silent after a host re-prepares (asynchronous rebuild).
- The bus-insert backdrop test threshold was loosened (0.05 → 0.10) and should
  be replaced with a sharper check.
- Release gates are paused; rerun all of `PX3_0.8.0_RELEASE_GATES.md` on final
  main. Notarization still needs a stored notarytool credential.
