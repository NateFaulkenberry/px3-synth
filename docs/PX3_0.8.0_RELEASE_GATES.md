## Open findings from `uinative` smoke run (unverified instrument)

- 50 of 50 `setState`→`getState` recalls are not byte-identical (24 KB state). Diagnostic added to print the first difference.
- Heap grew 89 MB → 726 MB across CPU/resize/preset/state/stale-cache phases. A per-phase memory print was added to isolate it. It may be a real leak.
- Idle message thread measured 59% of a core. An empty-window calibration was added to separate harness cost from editor cost.
- Lifecycle "first paint" was invalid because the window stayed visible; closing now hides it.
- Stale-cache pixel difference was 0.31%; a fresh-vs-fresh noise floor was added.
